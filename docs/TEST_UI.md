# API 테스트 화면 (/test-ui)

API 동작을 브라우저에서 눈으로 확인하는 **테스트 전용** 화면입니다. 고객용 쇼핑몰이 아니며 API 업무 로직은 바꾸지 않았습니다.

- 경로: `GET /test-ui` (예: http://127.0.0.1:8000/test-ui). 상단 메뉴 **API 테스트** 링크로도 이동합니다.
- 파일: `src/web/presentation/router.py`(`test_ui`), `src/templates/test_ui.html`, `src/static/test-ui.js`, `src/static/test-ui.css`
- 실행: README의 "안전하게 실행하기"와 같습니다. **새 실습 DB**와 `DEMO_SEED=true`(상품 20개, free 게시판)를 권장합니다.

## 안전 규칙

- 모든 동작의 `METHOD 경로 → HTTP 상태`와 응답 JSON을 오른쪽 **응답 기록**에 표시합니다.
- 키 이름에 token·password·authorization·secret·jti가 들어간 값은 `[숨김]`으로 표시합니다.
- JWT는 JS 메모리 변수에만 둡니다. 새로고침·페이지 이동·로그아웃 시 사라집니다. (localStorage·쿠키 미사용)
- 요청 중에는 모든 버튼이 비활성화됩니다.
- 화면 출력은 `textContent`/`new Option(text)`만 사용합니다. CSP는 외부·인라인 스크립트와 폼 기본 제출을 막습니다.

## 확인 체크리스트

### 정상 흐름

| # | 동작 | 기대 결과 |
|---|---|---|
| 1 | 회원가입 (예: `tester01`, `010-1234-5678`, 이메일, 이름, `Testpass1!`) | `POST /v1/users → 201`, password 없음 |
| 2 | 로그인 | `POST /v1/auth/login → 200`, access_token `[숨김]`, 상태 "로그인됨" |
| 3 | 상품 목록 불러오기 | `GET /v1/products?size=100 → 200`, 선택 목록에 재고 표시 |
| 4 | 상품 선택, 수량 2, 주문 생성 | `POST /v1/orders → 201`, status `PLACED`, 이어서 상품 재고 2 감소 |
| 5 | 내 주문 불러오기 | `GET /v1/orders?limit=100 → 200`, 방금 주문 표시 |
| 6 | 주문 선택 후 취소 | `POST /v1/orders/{id}/cancel → 200`, `CANCELLED`, 재고 원복 |
| 7 | 게시판 불러오기 → free 선택 → 글 목록 | `GET /v1/boards → 200`, `GET /v1/boards/free/posts → 200` |
| 8 | 제목·내용 입력 후 글 작성 | `POST /v1/boards/free/posts → 201`, 목록에 새 글 |
| 9 | 로그아웃 | `POST /v1/auth/logout → 204`, 상태 "로그아웃" |

### 오류·차단 흐름

| # | 동작 | 기대 결과 |
|---|---|---|
| 1 | 같은 이메일·아이디로 다시 가입 | 409 |
| 2 | 짧거나 규칙에 맞지 않는 비밀번호로 가입 | 422 (오류 메시지는 표시, 비밀번호 값은 없음) |
| 3 | 틀린 비밀번호로 로그인 | 401 |
| 4 | 로그아웃 상태에서 주문 생성·내 주문·로그아웃 | 401 |
| 5 | 재고보다 많은 수량 주문 | 409, 재고 변화 없음 |
| 6 | 수량 0 또는 상품 미선택 후 주문 | 수량 0은 브라우저 입력 검증, 상품 미선택은 서버 422 |
| 7 | 이미 취소한 주문을 다시 취소 | 409, 재고 추가 증가 없음 |
| 8 | 로그아웃 상태에서 free 게시판 글 작성 | 400 (비회원 이름·비밀번호 없음) |
| 9 | 빈 제목으로 글 작성 | 422 |
| 10 | 게시판·주문을 선택하지 않고 버튼 클릭 | "요청하지 않음" 기록, 서버 요청 없음 |
| 11 | 로그인 후 새로고침 | 상태 "로그아웃", 주문 조회 시 401 |
| 12 | 요청 중 버튼 반복 클릭 | 버튼 비활성화, 요청 1회만 기록 |

> 새로고침은 화면의 토큰만 지웁니다. 서버의 토큰은 만료 전까지 유효하므로, 서버에서 무효화하려면 로그아웃 버튼을 누르세요. 로그아웃한 토큰 재사용 401은 화면이 토큰을 지우므로 기존 테스트·Swagger로 확인합니다.

## 자동 테스트

```powershell
uv run python -m pytest -q tests/test_test_ui.py
```
